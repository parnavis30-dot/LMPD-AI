LMPD AI — FULL V1–V6 STARTER BUILD
=========================================

WHAT THIS BUILD INCLUDES
V1 - Upload local videos or enter a YouTube URL (only content you own / have permission to edit), transcribe speech, choose clip windows, crop to 9:16, export MP4.
V2 - Candidate ranking using transparent transcript signals: hook words, vocabulary variety, questions, speech density and sentence boundaries. The score is a heuristic, NOT a viral prediction.
V3 - Optional face-aware framing using OpenCV Haar face detection. This is a lightweight single-frame-position estimate, not robust multi-person identity tracking.
V4 - Animated word-by-word karaoke-style captions using Whisper word timestamps and ASS subtitle rendering.
V5 - Automatic title ideas and transcript-keyword hashtags.
V6 - Branded Streamlit creator dashboard with settings, previews and downloads.

REQUIREMENTS
- Windows 11, Python 3.11 64-bit
- Internet for first-time package installation and model download
- 16 GB RAM recommended for the base model
- FFmpeg: imageio-ffmpeg is installed as a dependency and supplies an FFmpeg binary.
- Processing is CPU-first. AMD GPU acceleration is not configured.

INSTALL / RUN
1. Install Python 3.11 (64-bit). Ensure the Python launcher `py` is available.
2. Extract the entire ZIP to a normal folder, e.g. Desktop\LMPD_AI_Full.
3. Open the extracted folder.
4. Double-click run.bat.
5. Wait for dependencies to install. The first install can take several minutes.
6. Streamlit should open a browser at http://localhost:8501.
7. Start with a short video (2–5 minutes) and model `base`.

OUTPUTS
Rendered MP4 clips, clip_metadata.json and transcript.txt are saved in the outputs folder.

IMPORTANT LIMITATIONS
- This is a working local starter, not a polished commercial SaaS or a guarantee of viral reach.
- V2 ranking is heuristic; no trained virality model or social-platform performance data is used.
- V3 uses OpenCV Haar face detection and a fixed estimated horizontal crop center per clip. It is not smooth frame-by-frame active-speaker tracking.
- V4 karaoke captions require speech words to be recognized by Whisper. Music-only clips may have no captions.
- V5 titles and hashtags are lightweight local template/keyword suggestions, not generated by a cloud LLM.
- Some videos with unusual codecs, variable frame rates, or complex audio tracks may fail to render.
- YouTube downloading is subject to YouTube terms and copyright. Use only videos you own or have explicit permission to download/edit.
- Keep the app running in the terminal while using it. Close the terminal to stop the local server.

TROUBLESHOOTING
- If `py -3.11` fails, install Python 3.11 and ensure Python Launcher is enabled.
- If packages fail to install, check internet and rerun run.bat.
- If model download fails, retry with a stable internet connection.
- If video rendering fails, try an MP4 H.264 source and a shorter test clip.
